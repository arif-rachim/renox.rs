Sign in

Paste a Renox token for your tenant. Create one with renox login, or for the dashboard only:

renox tokens create dashboard --scope apps:read --scope apps:write --scope deploy --scope logs:read --scope secrets:read --scope secrets:write --expires-days 7

The dashboard calls the control API at {{ api_host }} with this token, with your scopes and role. It is stored encrypted for this browser session and never shown again; signing out deletes it.
