Deleting the tenant removes every app, deployment, secret, domain, log line and meter row, the database on the node and every generation in the replica store, and the exports. It cannot be undone: a point-in-time restore is impossible from then on.

Only the owner can do it, from a signed-in API session (not with a token, so not from this dashboard): DELETE /v1/tenants/{{ tenant.id }} with {"confirm": "{{ tenant.id }}"}. Its progress then shows here.
