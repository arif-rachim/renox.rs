# create-renox

```sh
bun create renox myapp [--template <name>]
```

Creates a new [Renoxium](https://github.com/arif-rachim/renox.rs) app: it runs `renox new` from `@renoxium/cli`, at the same version. Requires Bun 1.4 or newer.

Installing the CLI: [docs/12-developer-experience.md](https://github.com/arif-rachim/renox.rs/blob/main/docs/12-developer-experience.md), "Installing the CLI".
