Specification

Runtime
A V8 isolate per tenant. CPU, memory, wall-clock and network limits are enforced in Rust, so a runaway loop in one app never slows another.
Data
One SQLite file per tenant, backed up continuously. Module tables are prefixed and every statement passes the SQLite authorizer.
Rendering
HTML templates rendered in Rust, htmx fragments, View Transitions, SSE and WebSockets. No SPA unless you want one.
Modules
Auth with 2FA and phone OTP, organizations and roles, billing, tax invoices, admin, storage, email and WhatsApp. Override a module's template without forking it.
Access
Cedar policies for roles, attributes and relations; route guards; queries scoped to the signed-in user.
Deploys
Every deploy is an immutable artifact. Promote, roll back, read logs and usage per app in the dashboard.
Cost
An idle app is evicted from memory and costs almost nothing. You pay for the requests, CPU and storage you use.

Folders are routes

pages/products/[id].html is /products/:id. A loader beside it reads the data; the template renders it. Configuration is the exception, not the rule.

  1. Write pages and functions. HTML for the page, TypeScript for its data.
  2. Install modules. renox add auth brings the tables, pages and policies.
  3. Deploy. renox deploy, and the app is live on its own address.
